# Little Tugs Family Child Care Website

This repository contains the GitHub Pages website for **Little Tugs Family Child Care** in Falmouth, Massachusetts.

## Live Site

https://littletugs.github.io/childcare/

## Files

- `index.html` — main website homepage
- `style.css` — website styles
- `images/` — site images and favicon assets
- `sitemap.xml` — sitemap submitted to search engines for URL discovery
- `BingSiteAuth.xml` — Bing Webmaster Tools verification file
- `googlebfc7a29fb6b7f25b.html` — Google Search Console verification file
- `README.md` — repository information and maintenance notes

## Search Engine Setup

The site includes verification files for:

- **Google Search Console**
- **Bing Webmaster Tools**

The sitemap is available at:

https://littletugs.github.io/childcare/sitemap.xml

When adding new public pages to the website, update `sitemap.xml` so search engines can discover them.

## Updating the Website

To publish changes:

1. Edit `index.html`, `style.css`, or other site files.
2. Commit the changes to the GitHub Pages publishing branch.
3. GitHub Pages will automatically deploy the updated site.

Changes may take a few minutes to appear on the live website.

## Important

Do not remove the following files while their corresponding webmaster services are in use:

- `BingSiteAuth.xml`
- `googlebfc7a29fb6b7f25b.html`

Removing them may cause ownership verification problems in Bing Webmaster Tools or Google Search Console.
